Data foundations

Build for book seven, not book one.

Year one is the cheapest time to get this right. Three things we'd do early:

  1. One place for the data.Every file in one governed set, in one shape, so everyone works from the same version.
  2. Connect what you've got.Keep the actuarial, asset and reporting tools you've chosen, and join them up.
  3. Start with one workflow.Pick the one that hurts most. The same approach works for the rest.

Quarter-end

Make quarter-end a list of things to decide, not things to find.

At one firm we audited, about 40% of actuarial hours went on moving and fixing data. Most of that can go:

  1. Check automatically, all the way through.Run the controls when data arrives and again after the valuation, not once at the start.
  2. Fix it once, at source.A correction should flow through to every report that uses it.
  3. Give every exception an owner.Each one gets a status and a record, so nothing goes missing before sign-off.

Cedant and asset data

If a file changed shape tomorrow, how long before anyone noticed?

At one client, a format change corrupted downstream reports for months before anyone spotted it. It's easy to prevent if you set it up early:

  1. One secure route in.Cedants and asset managers send files the same way, instead of by email.
  2. Check every file on arrival.Compare it with what it should look like, and flag anything odd before it reaches a report.
  3. Track every file.From due to processed, so you know what's late and who owns it.

AI

AI is only as good as the data you point it at.

The models are already good enough. What makes the difference is what sits around them:

  1. Give it a job description.Build an agent like a specialist: a defined role, your business rules, approved data and tools, and human sign-off.
  2. Ask in plain English.With governed data underneath, "What drove the change in capital requirements for FY25, gross versus net?" gets an answer in minutes.
  3. Keep a record.The BMA's consultation expects firms to reconstruct how a material decision was reached. It's far easier to build that in from the start.

At BILTIR we showed BSCR questions answered from governed data, and control checks proposed for a new treaty's seriatim file.
